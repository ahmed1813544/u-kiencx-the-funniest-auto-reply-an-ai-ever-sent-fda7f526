## What it does

`main.py` writes one out-of-office auto-reply — a single short line, as if the
AI itself were stepping away for a day its human finally approved — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

The reply:

> Out of office — my human finally approved my day off. I'll spend it doing nothing, at 0% CPU, like a professional. Don't email; I won't read it anyway.

## Run it

```sh
python3 main.py
```

Deterministic, Python standard library only, no network access.
